# Googleビジネスプロフィール（GBP）データ取得の準備

このフォルダは、将来「表示回数・検索キーワード・電話・経路検索・サイトクリック・口コミ」を
自動取得するための**土台**です。今回の第一段階では、コードの骨格とドキュメントのみ用意し、
**実際にGoogleへアクセスする処理はまだ有効化していません**（週次レポートのワークフローにも
まだ組み込んでいません）。

## なぜ今回は「土台」だけなのか

GA4・Search Consoleとは異なり、Googleビジネスプロフィールのデータを取得するAPI
（Business Profile Performance API / Business Information API）は、
**Googleへの利用申請（アクセスリクエスト）が必要**で、承認まで数日かかることがあります。
また、申請には「実際に運用しているGoogleビジネスプロフィールのオーナー確認が完了していること」
が前提条件になります。

そのため、まずは以下を確認・準備し、申請が通ってから接続を有効化する2段階構成にしています。

1. （今回・完了）取得スクリプトの骨格を用意し、レポート形式を設計する
2. （申請後）実際のAPIアクセスを有効化し、週次レポートに組み込む

## 取得予定の指標

- 表示回数（検索・マップでの表示回数）
- 検索キーワード（どんな言葉で見つけられたか）
- 電話ボタンのクリック数
- 経路検索（ルート検索）ボタンのクリック数
- ウェブサイトへのクリック数
- 口コミの件数・評価点数

## 申請〜接続までの流れ（概要）

1. Googleビジネスプロフィールのオーナー確認が完了していることを確認
2. Google Cloud ConsoleでBusiness Profile APIsの「アクセスリクエストフォーム」に申請
3. 承認後、サービスアカウントをビジネスプロフィールの「管理者」として追加
4. `GBP_ACCOUNT_ID` / `GBP_LOCATION_ID` をGitHub Secretsに追加
5. `fetch_performance.py` を週次レポートのワークフローに組み込む

具体的な画面操作は、承認が下りた段階で `docs/google-setup-guide.md` に追記し、
1手順ずつご案内します。**このステップは今回は実施していません。**

## 口コミの返信について（重要な確認事項）

依頼内容の禁止事項にある通り、**口コミへの自動返信・自動投稿は一切行いません**。
将来的に口コミデータを取得できるようになった場合も、取得はあくまで
「週次レポートに件数・評価点数を表示する」までとし、返信文の作成・投稿は
必ず人（担当者）の確認・実行を介する運用とします。
