# マッスルジム湘南 年末年始キャンペーンLP（/lp/winter/）

既存LP（リポジトリ直下 `index.html`）とは別ディレクトリに作成した、年末年始キャンペーン専用のランディングページです。
既存LPのファイルは一切変更していません。

## 含まれるもの（業者へそのまま渡せる一式）

```
lp/winter/
├── index.html                          … LP本体
├── assets/css/winter-20261027.css     … スタイル一式（このLP専用、既存CSSと独立）
├── assets/js/winter-20261026.js        … スクロール演出・固定CTAバー・計測イベント送出
├── assets/img/favicon.svg              … favicon（既存LPと共通デザイン）
├── assets/img/photos/                  … 実店舗の撮影写真（既存LPの使用許諾済み写真から、本LPで使うものだけを複製）
└── README.md                           … このファイル
```

すべて相対パス（`./`）で参照しているため、このディレクトリごとコピーすれば
GitHub Pagesのサブパスでも、業者サーバーの任意のサブディレクトリでもそのまま動作します。

## 配置方法

### GitHub Pages（このリポジトリで公開する場合）
`main`にマージ後、`https://taku12ygk.github.io/-muscle-gym-shonan-lp/lp/winter/` でそのまま表示されます。
追加設定は不要です。

### 業者サーバーに設置する場合（最終的な公開先）
`lp/winter/` フォルダの中身一式（`index.html`・`assets/`）を、設置したいディレクトリへ
そのままアップロードしてください。例：`https://example.com/winter/` に置く場合は
`lp/winter/`の中身を`winter/`直下にコピーするだけで動作します（相対パスのため、
ディレクトリ名を変えても調整不要です）。

**本番公開時に行う作業**（公開URLが決まってから）
1. `index.html` の `<meta name="robots" content="noindex,nofollow">` を、検索に載せる場合は `index,follow` に変更
2. `<head>` 内に `canonical`・`og:url`・`og:image`（公開URLを使った絶対URL）を追加
3. ページ上部の「確認用ページ｜公開前の内容です」（`preview-banner`）と、フッターの確認用の一文（`site-footer__preview-note`）を削除
4. フッターのプライバシーポリシー・特定商取引法の表記は、現在は既存LP（GitHub Pages）のページへ絶対URLでリンクしています。
   業者サーバー側に別のページを用意する場合は、リンク先を差し替えてください

## キャッシュ対策

CSS/JSのファイル名には更新日（`-20261026`）を付けています（同じ日に再更新した場合は末尾に
`b`・`c`…を付加）。将来このLPのデザイン・スクリプトを修正する際は、既存LP同様に
`winter.css`/`winter.js`を直接上書きせず、新しい日付のファイル名（例：`winter-20270110.css`）を
作成し、`index.html`内の参照を更新してください。

GTM側で既存LPと区別して計測できるよう、`cta_id`はすべて末尾に`_winter`等を付けて分離しています。

## 確定済みのキャンペーン条件

- 申込受付期間：2026年11月1日〜2027年1月31日（申込を受け付ける期間。特典・契約の利用期間ではない）
- 年末年始トリプルゼロキャンペーン（24時間コース・パーソナルコース）
  - 新規入会の方のみ
  - 入会金0円・事務手数料0円・初月会費0円（初月＝入会した月の月末まで）、6ヶ月継続契約
  - 定員：24時間コース30名、パーソナルコース15名
  - 24時間コースの通常月会費：月額7,200円（税込）。入会月の翌月から適用
  - 6ヶ月未満で退会する場合：残りの月数分の会費を支払うことで退会可能
- プレミアムコース：全4プラン30%OFF（金額はすべて税込、各プランの契約期間中の総額）
  - 1ヶ月・全8回：通常100,000円 → 70,000円
  - 2ヶ月・全16回：通常200,000円 → 140,000円
  - 3ヶ月・全24回：通常300,000円 → 210,000円
  - 4ヶ月・全32回：通常400,000円 → 280,000円（最大120,000円OFF）
  - 入会金0円・事務手数料0円が適用。初月会費0円・6ヶ月継続契約の条件は適用しない
  - 契約期間は選択した1〜4ヶ月
  - 定員：5名
- トリプルゼロ・プレミアムとも、他のキャンペーン・特典との併用不可
- 接骨院「通い放題」の詳細・LINE食事管理の運用ルールは、LP上では「LINEでご案内」とする（確定）
- 24時間ジムの見学：受付あり（見学の料金は未確認のため、「無料」とは表記していない）
- 最終的な公開先：業者サーバー

上記は料金カード・FAQ・注意事項（キャンペーン条件まとめ）で同じ表現に統一しています。
