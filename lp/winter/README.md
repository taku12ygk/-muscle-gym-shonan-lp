# マッスルジム湘南 年末年始キャンペーンLP（/lp/winter/）

既存LP（リポジトリ直下 `index.html`）とは別ディレクトリに作成した、年末年始キャンペーン専用のランディングページです。
既存LPのファイルは一切変更していません。

## 含まれるもの（業者へそのまま渡せる一式）

```
lp/winter/
├── index.html                          … LP本体
├── assets/css/winter-20261026.css      … スタイル一式（このLP専用、既存CSSと独立）
├── assets/js/winter-20261026.js        … スクロール演出・固定CTAバー・計測イベント送出
├── assets/img/favicon.svg              … favicon（既存LPと共通デザイン）
├── assets/img/photos/                  … 実店舗の撮影写真（既存LPの使用許諾済み写真から、本LPで使うものだけを複製）
└── README.md                           … このファイル
```

すべて相対パス（`./`）で参照しているため、このディレクトリごとコピーすれば
GitHub Pagesのサブパスでも、業者サーバーの任意のサブディレクトリでもそのまま動作します。

## 配置方法

### GitHub Pages（このリポジトリで公開する場合）
`main`にマージ後、`https://taku12ygk.github.io/-muscle-gym-shonan-lp/lp/winter/` でそのまま表示されます。
追加設定は不要です。

### 業者サーバー等、別の場所に設置する場合
`lp/winter/` フォルダの中身一式（`index.html`・`assets/`）を、設置したいディレクトリへ
そのままアップロードしてください。例：`https://example.com/winter/` に置く場合は
`lp/winter/`の中身を`winter/`直下にコピーするだけで動作します（相対パスのため、
ディレクトリ名を変えても調整不要です）。

## キャッシュ対策

CSS/JSのファイル名には作成日（`-20261026`）を付けています。将来このLPのデザイン・スクリプトを
修正する際は、既存LP同様に`winter.css`/`winter.js`を直接上書きせず、新しい日付のファイル名
（例：`winter-20270110.css`）を作成し、`index.html`内の参照を更新してください。

## 計測（CTAクリックの`cta_id`一覧）

既存LPと同じ仕組み（`window.dataLayer`への`cta_click`イベント送出）を使用しつつ、
GTM側で既存LPと区別して計測できるよう、`cta_id`はすべて末尾に`_winter`等を付けて分離しています。
LINEのリンク先（`https://lin.ee/5dk5BNG`）自体は既存LPと同じものを使用しています。

| cta_id | 設置場所 |
|---|---|
| `line_hero_winter` | ファーストビュー |
| `line_triple0` | トリプルゼロキャンペーン直後 |
| `line_premium` | プレミアムコース（通常CTAとは別の文言「LINEでプレミアムを相談する」） |
| `line_flow_winter` | 体験の流れ |
| `line_access_winter` | アクセス |
| `line_closing_winter` | 最終CTA |
| `line_sticky_winter` | スマホ固定バー |
| `tel_header_winter` / `tel_sticky_winter` / `tel_access_winter` | 電話ボタン |
| `tel_access_peace_winter` | 電話ボタン（PEACE接骨院） |
| `mail_access_winter` | メールボタン |
| `map_access_winter` | Googleマップボタン |

**注意**：LINEボタンのクリックは「導線クリック」の計測であり、「予約完了」ではありません。
既存LPの`docs/measurement-plan.md`と同じ考え方です。
