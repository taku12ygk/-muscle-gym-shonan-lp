# Google連携 設定手順書（初心者向け）

この手順書は、マッスルジム湘南店LPを Google Search Console・GA4（アクセス解析）・GTM（タグ管理）・
週次レポート自動化 に接続するための操作を、画面ごとに1つずつまとめたものです。

**重要**：この手順書に書かれた操作は、すべて**当社のGoogleアカウントで、当社ご自身が行ってください**。
パスワードやAPIキー（下記で出てくる「JSONキー」などの秘密情報）は、**チャットには絶対に貼らないでください**。
実際に操作するときは、この手順書を見ながら1つずつ進め、分からない箇所だけ聞いていただければ、
その画面・そのボタンだけをご案内します。

用語がいくつか出てきますが、覚える必要はありません。都度この手順書で説明します。

- **GA4（Googleアナリティクス4）**：サイトに何人来て、どのボタンが押されたか等を確認できる無料のGoogleサービス
- **GTM（Googleタグマネージャー）**：計測用のコードをまとめて管理できる無料のGoogleサービス（直接HTMLを触らずに済む）
- **Search Console**：Google検索で「何位に表示されているか」「どんな言葉で検索されて来ているか」が分かる無料サービス
- **サービスアカウント**：人間ではなく、プログラム（今回は週次レポートの自動処理）がGoogleのデータを読み取るための、専用の“ロボット用アカウント”
- **JSONキー**：サービスアカウントの合鍵のようなファイル。パスワードと同じくらい重要なので、他人に渡したりチャットに貼ったりしないでください

---

## ステップ0：全体の流れ

1. Search Console にサイトを登録する
2. GA4 のプロパティを作る
3. GTM のコンテナを作り、サイトに設置してGA4・コンバージョンと接続する
4. 週次レポート自動化のための「サービスアカウント」を作る
5. サービスアカウントに、GA4とSearch Consoleの閲覧権限を渡す
6. GitHubの「Secrets（秘密の設定欄）」に、必要な情報を登録する

このリポジトリ側（コードやワークフロー）の準備は完了しています。
上記1〜6は、すべてブラウザでGoogle・GitHubの画面を操作する作業です。

---

## ステップ1：Google Search Console にサイトを登録する

1. ブラウザで https://search.google.com/search-console にアクセスし、当社のGoogleアカウントでログインします。
2. 左上の「プロパティを追加」（初回は中央に表示）をクリックします。
3. 「URLプレフィックス」の欄に `https://taku12ygk.github.io/-muscle-gym-shonan-lp/` を入力し、「続行」ボタンを押します。
4. 所有権の確認方法がいくつか表示されます。「HTMLタグ」の方法を選ぶと、`<meta name="google-site-verification" content="...">` という1行のコードが表示されます。
5. その1行を私（Claude）に伝えていただければ、`index.html` の該当箇所に追加してPRを作成します（コード変更が必要なため、私が対応します）。
6. コードが反映されたのを確認してから、Search Console画面の「確認」ボタンを押します。

> すでにSearch Console登録が済んでいる場合は、このステップは不要です。「登録済みです」とだけ教えてください。

---

## ステップ2：GA4（Googleアナリティクス）のプロパティを作る

1. https://analytics.google.com にアクセスし、当社のGoogleアカウントでログインします。
2. 左下の「管理」（歯車アイコン）をクリックします。
3. 「プロパティを作成」ボタンを押します。
4. プロパティ名に「マッスルジム湘南店LP」などわかりやすい名前を入力し、タイムゾーンを「日本」、通貨を「日本円」にして「次へ」を押します。
5. 業種・ビジネスの規模は、当てはまるものを選んで「次へ」→「作成」を押します。
6. 「データストリーム」の画面で「ウェブ」を選び、ウェブサイトのURLに `https://taku12ygk.github.io/-muscle-gym-shonan-lp/` を入力し、ストリーム名に「マッスルジム湘南店LP」と入力して「ストリームを作成」を押します。
7. 作成後の画面に「測定ID」（`G-`から始まる文字列）が表示されます。この測定IDをメモしてください（これは秘密情報ではないので、チャットで共有していただいて構いません）。

---

## ステップ3：GTM（Googleタグマネージャー）のコンテナを作り、サイトに設置する

1. https://tagmanager.google.com にアクセスし、当社のGoogleアカウントでログインします。
2. 「アカウントを作成」ボタンを押し、アカウント名に「マッスルジム湘南」、コンテナ名に「マッスルジム湘南店LP」、
   プラットフォームは「ウェブ」を選んで「作成」を押します。
3. 表示された「コンテナID」（`GTM-`から始まる文字列）をメモしてください（これも秘密情報ではありません）。
4. 測定ID（`G-...`）とコンテナID（`GTM-...`）を私に伝えていただければ、`index.html` の
   計測タグ設置スロット（すでに用意されているコメント部分）にGTMのコードを追加し、GTM管理画面で
   GA4の設定タグと、`docs/measurement-plan.md` に記載したコンバージョン用トリガー
   （LINEボタン・電話ボタン・Googleマップボタン・メールボタン）を設定する手順をご案内します。
   ※GTM管理画面上でのタグ・トリガー作成はGoogle側の操作のため、実際にクリックする箇所は
   その都度1つずつ画面名とボタン名でご案内します。
5. GTMの「プレビュー」モードで、公開前に必ず動作確認します（この段階ではまだ本番のサイトに反映されません）。
6. 動作確認ができたら、GTM画面右上の「公開」ボタンを押していただくことで、初めて計測が有効になります。
   **この「公開」ボタンは当社の判断で押してください**（Claudeが勝手に公開することはありません）。

## ステップ4：週次レポート自動化用の「サービスアカウント」を作る

ここからは、GA4・Search Consoleのデータを**自動で**取得するための準備です。少し専門的ですが、
ボタンを押す場所だけ分かれば大丈夫です。

1. https://console.cloud.google.com にアクセスし、当社のGoogleアカウントでログインします。
2. 画面上部の「プロジェクトを選択」→「新しいプロジェクト」を押します。プロジェクト名に
   「muscle-gym-shonan-report」などと入力し、「作成」を押します。
3. 作成したプロジェクトを選択した状態で、検索窓に「Google Analytics Data API」と入力し、
   表示された項目をクリックして「有効にする」を押します。
4. 同様に検索窓で「Google Search Console API」を検索し、「有効にする」を押します。
5. 左側メニューの「APIとサービス」→「認証情報」を開き、「認証情報を作成」→「サービスアカウント」を選びます。
6. サービスアカウント名に「weekly-report-bot」などと入力し、「作成して続行」→（役割の設定はそのまま）「続行」→「完了」を押します。
7. 作成されたサービスアカウントの一覧から、今作ったものをクリックします。
8. 上部タブの「鍵」を選び、「鍵を追加」→「新しい鍵を作成」→「JSON」を選んで「作成」を押すと、
   JSONファイルが自動でパソコンにダウンロードされます。

   ⚠️ **このJSONファイルは、パスワードと同じくらい重要な秘密情報です。**
   **チャットには絶対に貼らないでください。** 次のステップ6で、GitHubの画面から直接登録します。

9. サービスアカウントの詳細画面に表示されている「メール」（`xxxx@xxxx.iam.gserviceaccount.com` の形式）をメモしてください。
   これはステップ5で使います（このメールアドレス自体は秘密情報ではありません）。

## ステップ5：サービスアカウントに、GA4とSearch Consoleの閲覧権限を渡す

1. GA4管理画面（https://analytics.google.com → 管理）で「プロパティのアクセス管理」を開き、
   右上の「＋」→「ユーザーを追加」を押します。
2. ステップ4の9でメモしたサービスアカウントのメールアドレスを入力し、役割は「閲覧者」を選んで「追加」を押します。
3. Search Console（https://search.google.com/search-console）で、登録したプロパティを開き、
   左メニューの「設定」→「ユーザーとアクセス権限」→「ユーザーを追加」を押します。
4. 同じサービスアカウントのメールアドレスを入力し、権限は「フル」または「制限付き」（閲覧のみで十分です）を選んで追加します。

---

## ステップ6：GitHubのSecrets（秘密の設定欄）に登録する

GitHubには、パスワードやAPIキーを安全に保存できる専用の欄（Secrets）があります。
**ここに登録した内容は、リポジトリのコードやPRには一切表示されません。**

1. ブラウザで `https://github.com/taku12ygk/-muscle-gym-shonan-lp` を開きます。
2. 上部タブの「Settings」（設定）をクリックします。
3. 左メニューの「Secrets and variables」→「Actions」をクリックします。
4. 「New repository secret」ボタンを押します。
5. 以下の3つを、1つずつ同じ手順で登録します。

   | Name（名前） | Secret（値） |
   |---|---|
   | `GOOGLE_SERVICE_ACCOUNT_JSON` | ステップ4-8でダウンロードしたJSONファイルの中身を、すべてコピーして貼り付け |
   | `GA4_PROPERTY_ID` | ステップ2で作成したGA4プロパティのID（数字のみ。GA4管理画面の「プロパティの詳細」に表示されています） |
   | `GSC_SITE_URL` | `https://taku12ygk.github.io/-muscle-gym-shonan-lp/`（Search Consoleに登録したURLと同じもの） |

6. 3つとも登録が終わったら、GitHubの「Actions」タブ→「週次SEO/MEOレポート」を開き、
   「Run workflow」ボタンを押すと、今すぐ試しに1回レポートを生成できます。
   （通常は毎週月曜9:00に自動で実行されるため、普段はこのボタンを押す必要はありません。）
7. 数分後、リポジトリの「Issues」タブに「📊 週次レポート」というタイトルの投稿が届けば成功です。
