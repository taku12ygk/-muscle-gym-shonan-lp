# 計測設計書（LINE・電話・問い合わせ・予約・Googleマップ）

このドキュメントは、成果（コンバージョン）の計測を「何で・どう測るか」をまとめた設計図です。
実際にGoogle広告・GA4・GTMへ数値を送る作業は、Googleアカウントでの設定（手順書 `docs/google-setup-guide.md` 参照）が必要なため、
本ドキュメントでは **今のサイトに何があり、何が足りないか、二重計測をどう防ぐか** を整理します。

## 1. 今のサイトにすでにある仕組み

`assets/js/main-20260903.js` が、サイト内の全CTA（行動喚起ボタン）のクリックを検知し、
ブラウザ内の `window.dataLayer` へ以下の形式で自動記録しています（**まだGoogleには送信していません**。あくまで記録の準備です）。

```js
{
  event: "cta_click",
  cta_id: "line_hero" | "tel_header" | ... ,
  cta_label: "ボタンの表示テキスト",
  cta_href: "遷移先URL"
}
```

## 2. 依頼いただいた5つの成果指標と、現状のカバー状況

| 依頼された成果指標 | 現状 | 備考 |
|---|---|---|
| LINEボタン | ✅ クリックは計測準備済み | GTM連携後、`cta_id`が`line_`で始まるクリックをコンバージョンにできます |
| 電話ボタン | ✅ クリックは計測準備済み | `cta_id`が`tel_`で始まるクリック |
| Googleマップボタン | ✅ クリックは計測準備済み | `cta_id`が`map_access` |
| 問い合わせ完了 | 🔶 「メールボタンを押した」までは計測可 | サイト内に問い合わせフォームがないため、「メールを実際に送信したか」はサイト側では分かりません |
| 体験・見学予約 | 🔶 「LINEボタンを押した」までは計測可 | 予約自体はLINE公式アカウント上でのやり取りのため、「本当に予約が完了したか」はLINE側の情報が必要です |

➡️ **確認が必要な点**：「問い合わせ完了」「体験・見学予約」を、②サイト側のボタンクリック（見込み）で近似するのか、
③LINE公式アカウント管理画面の数値と突き合わせて正確に見るのか、方針を決めていただく必要があります。
（③の場合、LINE公式アカウント管理画面の「友だち追加数」等を週次レポートに手動で追記する運用が現実的です。）

## 3. 二重計測（同じクリックが2回カウントされる）を防ぐ設計

今後GTM・GA4を導入する際、以下のルールを守ることで二重計測を防ぎます。

1. **GA4の計測タグは1か所だけに置く**：`index.html`に直接gtag.jsを書く方法と、GTM経由でGA4を設定する方法を
   **両方同時に使わない**。本サイトは「GTM経由でGA4を設定する」方式を採用します（README・head内のコメントに記載済み）。
2. **クリックイベントの発生元を1つに統一する**：GTMの組み込み「リンククリック」トリガーを別途作らず、
   既存の `cta_click`（dataLayerイベント）だけをGTM側のトリガーにする。同じボタンに2つのトリガーを重ねて設定しない。
3. **コンバージョンタグは`cta_id`ごとに1つ**：例えば「LINEボタン」のコンバージョンは、`cta_id`が`line_`で始まる
   クリックすべてに対して**1つのGA4イベントタグ**で対応し、ボタンの数だけタグを増やさない。
4. **Google広告のコンバージョンタグは、GA4側のコンバージョンイベントをインポートする方式を基本とする**：
   Google広告タグを直接HTMLに追加する方式は使わず、GTM→GA4→Google広告（インポート）の一本の流れにする。
5. **導入後は「テストモード（GTMのプレビュー）」で必ず動作確認してから公開する**：本番反映前に、
   クリック1回につきイベントが1回だけ発生することを目視確認します。

## 4. 今後、GTMで設定するトリガー例（設定時にそのまま使える一覧）

| GA4イベント名（例） | トリガー条件 | 対応する成果指標 |
|---|---|---|
| `line_click` | `event` equals `cta_click` AND `cta_id` starts with `line_` | LINEボタン |
| `tel_click` | `event` equals `cta_click` AND `cta_id` starts with `tel_` | 電話ボタン |
| `map_click` | `event` equals `cta_click` AND `cta_id` equals `map_access` | Googleマップボタン |
| `mail_click` | `event` equals `cta_click` AND `cta_id` equals `mail_access` | 問い合わせ（メール） |

上記はGTM側の「カスタムイベント」トリガーとして、`docs/google-setup-guide.md`の手順で設定します。
**コードの変更は不要**です（すでにdataLayerへ送出済みのため）。
